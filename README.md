# 🧠 Ишка — своя нейросеть для программирования

Нейросеть-трансформер, написанная **с нуля на Rust**: свой токенизатор, своя модель (архитектура как у Llama),
своё обучение на видеокарте NVIDIA и веб-чат, через который ты учишь её прямо в браузере.

- **Модель:** декодер-трансформер (RMSNorm, RoPE, SwiGLU), размеры от 1.4M до 520M параметров.
  Пресет `base` весит **~1 ГБ** (240M параметров).
- **«Думает»:** перед ответом пишет размышления в блоке `<|think|>…<|/think|>`, их видно в чате.
- **Учится от тебя:** в чате жмёшь «Исправить и научить», пишешь правильный ответ, потом «Обучить на примерах».
- **Работает офлайн** на твоём компьютере, данные никуда не уходят.

## ⚠ Честно о том, чего ждать

Модель обучается **с нуля**, поэтому сначала она не знает ничего, даже букв. Насколько она будет умной,
зависит от того, **сколько кода она увидит** и **сколько времени будет учиться**:

| Этап | Что нужно | Что получится |
|---|---|---|
| Предобучение `small` на ~1 млрд токенов | часы или сутки на GPU | дописывает код, похожий на настоящий |
| Предобучение `base` на ~5 млрд токенов | дни на хорошей видеокарте | уверенно дописывает функции |
| + дообучение на диалогах с размышлениями | тысячи примеров | отвечает на задачи в чате, «думает» |

Уровня Claude или ChatGPT она не достигнет: такие модели в сотни раз больше и обучаются на тысячах видеокарт.
Но это **полностью твоя** нейросеть, и её можно сколько угодно доучивать.

## 1. Установка

1. Установи Rust: <https://rustup.rs>.
2. Установи драйвер NVIDIA и **CUDA Toolkit** 12.x или 13.x: <https://developer.nvidia.com/cuda-downloads>.
   Проверка: команда `nvcc --version` должна работать.
3. Собери программу с поддержкой видеокарты:

```bash
cargo build --release --features cuda
```

Программа появится в `target/release/ishka` (на Windows `target\release\ishka.exe`).
В командах ниже она для краткости называется просто `ishka`.
Без `--features cuda` всё тоже работает, но на процессоре, то есть очень медленно.

### Windows: важно

**Проще всего:** запусти из PowerShell в папке проекта `.\build-windows.bat 89` (число — архитектура видеокарты, см. ниже).
Скрипт сам найдёт Visual Studio, подключит компилятор C++ и соберёт программу с CUDA.

Если собираешь вручную:

- Собирай **не в обычном PowerShell**, а в **«x64 Native Tools Command Prompt for VS»** (найди через Пуск).
  Иначе будет ошибка `nvcc fatal: Cannot find compiler 'cl.exe' in PATH`. Проверка: `where cl` должна найти файл.
  Если такого ярлыка нет, доустанови Visual Studio Build Tools с компонентом «Разработка классических приложений на C++».
- Номер архитектуры видеокарты задаётся так (RTX 20xx → 75, 30xx → 86, 40xx → 89, 50xx → 120):
  - в «Command Prompt» (cmd): `set CUDA_COMPUTE_CAP=89`
  - в PowerShell: `$env:CUDA_COMPUTE_CAP="89"` (команда `set` там **не работает**)
- Запуск программы: в cmd `target\release\ishka.exe …`, в PowerShell `.\target\release\ishka.exe …`.
- Если nvcc ругается на неподдерживаемую версию Visual Studio: `set NVCC_APPEND_FLAGS=-allow-unsupported-compiler`.
- CUDA 13 при ручной сборке: `set NVCC_APPEND_FLAGS=-Xcompiler /Zc:preprocessor`, иначе ошибка
  `C1189 … traditional preprocessor` (скрипт `build-windows.bat` делает это сам).

## 2. Собери данные (код, на котором она будет учиться)

Нужна папка с исходниками. Чем больше и качественнее код, тем умнее модель.

- **Свои проекты**, просто укажи на них папку.
- **Репозитории с GitHub:** клонируй популярные проекты на нужных языках:
  ```bash
  mkdir corpus && cd corpus
  git clone --depth 1 https://github.com/rust-lang/rust
  git clone --depth 1 https://github.com/tokio-rs/tokio
  # …чем больше, тем лучше: десятки и сотни репозиториев
  ```
- **Готовые датасеты с Hugging Face** (например, `bigcode/the-stack-smol`, `codeparrot/github-code-clean`)
  в формате `.jsonl` с полем `content` или `text`. Если датасет в формате `.parquet`, переведи его в jsonl,
  например, утилитой [DuckDB](https://duckdb.org):
  `duckdb -c "COPY (SELECT content FROM 'train.parquet') TO 'train.jsonl' (FORMAT JSON)"`

Папки `.git`, `node_modules`, `target` и файлы больше 512 КБ пропускаются автоматически.

## 3. Обучение с нуля, по шагам

```bash
# 1) Словарь токенов (5–20 минут)
ishka tokenizer --input corpus --vocab-size 32000

# 2) Перевести корпус в токены → data/pretrain/train.bin и val.bin
ishka prepare --input corpus

# 3) Создать модель (base ≈ 1 ГБ; начать можно с small, она обучается быстрее)
ishka init --preset base

# 4) Предобучение. Прогресс сохраняется каждые 1000 шагов;
#    если прервать (Ctrl+C), повторный запуск продолжит с последнего сохранения.
ishka train --data data/pretrain --steps 50000
```

Что смотреть в логе:
- `loss` должен падать. Для кода хороший результат около 1.0–1.5, сначала будет ~10.
- `val loss` — проверка на коде, которого модель не видела. Если он растёт, а `loss` падает, данных мало.
- `ток/с` — скорость. Время обучения ≈ (сколько токенов хочешь показать) / (ток/с).

Если вылетает **out of memory** (не хватило видеопамяти), уменьши батч или длину контекста:

| Видеопамять | Параметры для `base` |
|---|---|
| 8 ГБ | `--micro-batch 1 --accum 32 --seq-len 512 --dtype bf16` |
| 12 ГБ | `--micro-batch 2 --accum 16 --seq-len 1024 --dtype bf16` |
| 24 ГБ | `--micro-batch 8 --accum 4` |

`--dtype bf16` ускоряет обучение и экономит память на RTX 30xx/40xx/50xx.

Проверить, что получилось:
```bash
ishka generate --prompt "fn fibonacci(n: u64) -> u64 {"
```

## 4. Научить её общаться и думать (дообучение на диалогах)

После предобучения модель умеет только продолжать код. Чтобы она отвечала на вопросы, дообучи её на диалогах.
Файл `.jsonl`, по одному примеру на строку:

```json
{"messages": [{"role": "user", "content": "Напиши функцию, которая переворачивает строку"}, {"role": "assistant", "thinking": "Нужно пройти по символам с конца. В Rust удобно через chars().rev().", "content": "```rust\nfn reverse(s: &str) -> String {\n    s.chars().rev().collect()\n}\n```"}]}
```

Также понимаются форматы Alpaca (`instruction` / `input` / `output`), ShareGPT (`conversations`)
и размышления внутри ответа в виде `<think>…</think>`. Так что подойдут многие открытые датасеты
с задачами по программированию, в том числе с цепочками рассуждений.

```bash
ishka train --sft data/chat.jsonl --fresh --steps 3000 --lr 5e-5 --warmup 100
```

`--fresh` начинает новый отсчёт шагов и сбрасывает оптимизатор, а веса остаются от предобучения.

## 5. Веб-чат: разговаривай и учи её

```bash
ishka serve
```

Открой <http://127.0.0.1:8080>. В чате можно:

- задавать задачи и смотреть, как она «думает» (раскрывающийся блок 💭);
- нажать **«👍 Хороший ответ — запомнить»**, чтобы сохранить удачный ответ как пример;
- нажать **«✏️ Исправить и научить»**, написать правильный ответ (и, если хочешь, ход мыслей) и сохранить;
- нажать **«Обучить на примерах»**: модель дообучится на всех твоих примерах прямо из браузера
  и сохранится. Перед обучением делается резервная копия `model.before-teach.safetensors`.

Твои примеры копятся в `models/ishka/feedback.jsonl`. Их же можно использовать для большого
дообучения: `ishka train --sft models/ishka/feedback.jsonl,data/chat.jsonl --fresh`.

## Что где лежит

```
src/tokenizer.rs   байтовый BPE-токенизатор (обучение, кодирование)
src/model.rs       трансформер: внимание, RoPE, SwiGLU, KV-кэш
src/train.rs       AdamW, накопление градиентов, расписание lr, сохранение
src/data.rs        чтение корпуса, батчи для предобучения и диалогов
src/chat.rs        формат диалога, разбор датасетов
src/generate.rs    генерация с температурой, top-k/top-p, штрафом за повторы
src/server.rs      веб-сервер: чат (потоково), сохранение примеров, обучение
static/index.html  интерфейс чата
models/ishka/      твоя модель: config.json, tokenizer.json, model.safetensors
```

Пресеты (`ishka init --preset …`):

| Пресет | Параметры | Размер (f32) | Слоёв | Контекст |
|---|---|---|---|---|
| `tiny` | ~5M | ~20 МБ | 4 | 256 |
| `small` | ~42M | ~170 МБ | 8 | 1024 |
| `base` | ~240M | **~1 ГБ** | 16 | 1024 |
| `large` | ~520M | ~2 ГБ | 24 | 2048 |

Размеры указаны для словаря на 32000 токенов.

Тесты: `cargo test --release`.
